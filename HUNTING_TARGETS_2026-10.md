## 3. CHF (Fr.)

Swiss programs exist but mostly pay in **EUR via YesWeHack**, not CHF:

- **Swiss Post** — pays via YesWeHack in EUR (historically ~CHF 250,000 paid out in total; e-voting pilot in 2019 was CHF-denominated).
- **Swisscom** — runs its own program covering all Swiss Group products/subsidiaries; historically reported CHF 350,000/year in bounties. **Status and current table unverified — check swisscom.ch/bugbounty directly.**
- Swiss orgs on YesWeHack: Infomaniak, OneDoc, Swiss Post. University of Basel is on Intigriti but **VDP only, no bounty**.

**Verdict:** treat CHF as "Swiss targets, EUR payouts". There is no meaningful set of CHF-denominated public programs.

## 4. Dinars (KWD / BHD / JOD / etc.)

Honest answer: **there is effectively no public bug bounty program that pays in dinars.** What exists:

- **Gulf Bank (Kuwait)** — program via YesWeHack, rewards stated **up to USD 1,200**, bank-determined severity. Paid in USD, not KWD.
- **bugbounty.ae (UAE National / Cyber Security Council)** — classified **private/invite-only** in the disclose.io platform registry. Piloted with Etisalat and du; monetary rewards possible. Not open signup.
- **bugbounty.sa (Saudi, SAFCSP-backed)** — registry lists it as **private programs only**.
- **bugbounty.qa (Qatar)** — listed in the registry; no public reward data found; payment status unconfirmed.
- **Bugloud (UAE)** — the one regional platform with **public** programs; no published reward figures found.
- **Majid Al Futtaim / Carrefour (UAE)** — public program on **Bugcrowd**, pays USD.
- **Bahrain** — nothing found.

Do not build the $20k plan on this bucket. Register with Bugloud and bugbounty.qa as a side bet; income will come from EUR/USD programs.

## 8. Reality check on $20,000 in 2 months

The math, not encouragement:

- **EUR web programs route:** average realistic payout per accepted medium/high is €300–€1,500.
  $20k ≈ **15–40 accepted findings in 8 weeks** on mature programs. That is a full-time, high-volume
  recon operation, and it is how most people *fail* this target.
- **Monzo data point:** average payout **£441**. ~34 accepted Monzo bugs to hit £15k. Not the route.
- **High-ceiling route:** **one** confirmed high/critical on Kiteworks ($50k ceiling), Vercel Sandbox
  ($50k), d-you/EUDI Wallet ($40k), Doctolib (€50k), Swiss Post e-voting, or any §5a crypto program
  clears the whole target. Lower probability per hour, far higher expected value per hour **given your
  demonstrated skill set** (the Fireblocks MPC library work in this repo — native code + threshold
  cryptography review is rare and underserved).
- **Chrome VRP route:** base memory-safety is $2,000/bug post-2026-10-13; $20k ≈ 10 accepted memory
  bugs, or 1 controlled-write in a privileged process + a few others. Viable *only* with a working
  fuzzing pipeline (plus the reinstated $2,000 novel-fuzzer bonus).

**Recommended allocation for 8 weeks:** pick **3 deep targets, not 30 shallow ones.**
1. **Kiteworks** — downloadable appliance, new program, $50k ceiling, native+web+privileged daemons.
2. **One §5a crypto target with MPC/threshold/zk surface** — sBTC, SP1, SSV Network, or 1inch Wallet.
3. **d-you / German EUDI Wallet** *or* **Swiss Post e-voting** — published source, cryptographic
   protocol scope, EU-regulated, new scope added Sept 2026.

Keep a 20% time slice for **fresh-scope sweeps** (re-check the newest-programs list weekly) since new
assets are where low-hanging duplicates haven't been taken yet.

**Caveats that will actually bite:** KYC/tax paperwork delays payouts (crypto platforms especially —
budget 2–6 weeks from accept to paid, so bugs found in week 8 likely pay *after* your window);
triage queues on mature programs run weeks; duplicate rates on Doctolib/Adobe/NVIDIA are high; several
"max" figures above come from aggregator pages, not program policies — **verify before committing time.**
